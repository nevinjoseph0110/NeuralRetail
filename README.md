# 🛒 NeuralRetail – AI Retail Analytics System

## 📌 Overview
NeuralRetail is an AI-powered retail analytics platform developed using machine learning and data analytics techniques.

The system helps retail businesses:
- Analyze sales trends
- Predict future demand
- Segment customers
- Predict customer churn

---

## Features
- Sales Analytics Dashboard
- Demand Forecasting using Prophet
- Customer Segmentation using KMeans
- Churn Prediction using XGBoost
- Streamlit Dashboard
- FastAPI Backend API

---

## 🛠 Technologies Used
- Python
- Pandas
- Scikit-learn
- XGBoost
- Prophet
- Streamlit
- FastAPI

---

## ▶️ Run Project

### Activate virtual environment

venv\Scripts\activate

### Run Dashboard

streamlit run dashboard/app.py

### Run API

uvicorn api.main:app --reload
