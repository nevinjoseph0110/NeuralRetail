# NeuralRetail – AI Retail Analytics System

## Introduction
NeuralRetail is an AI-powered retail analytics platform designed to analyze retail sales data using machine learning and predictive analytics.

---

## Objectives
- Analyze retail sales trends
- Forecast future demand
- Segment customers
- Predict customer churn

---

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Prophet
- XGBoost
- Streamlit
- FastAPI

---

## Modules Implemented

### 1. Data Cleaning
- Removed null values
- Removed duplicates
- Created TotalPrice feature

### 2. Exploratory Data Analysis
- Sales trends
- Top products
- Customer analysis

### 3. Customer Segmentation
- RFM analysis
- KMeans clustering

### 4. Demand Forecasting
- Prophet forecasting model

### 5. Churn Prediction
- XGBoost classification model

### 6. Dashboard
- Streamlit analytics dashboard

### 7. API
- FastAPI backend service

---

## Results
- Successfully predicted customer churn
- Forecasted future sales
- Segmented customers into groups
- Built interactive dashboard

---

## Conclusion
NeuralRetail demonstrates how machine learning and analytics can improve retail business decision-making using forecasting, segmentation, and churn prediction.
